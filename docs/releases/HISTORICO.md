# Histórico de versões

Cada versão tem suas notas completas em `docs/releases/vX.Y.Z.md` (texto pronto para colar na Release do GitHub). O zip traz na raiz só o `README_vX.Y.Z.md` da versão atual.

| Versão | Título | Resumo |
|---|---|---|
| 1.5.0 | Stable repository checks | repository checks tolerate leftover old uninstaller/notes after extracting a zip over an old checkout (CI fix) |
| 1.4.0 | Phone view with QR code | view-only phone page over the local network (QR code, token, separate LAN-only server, off by default) |
| 1.3.1 | All artists on screen | Spotify tracks show every artist (read from the Spotify window title) |
| 1.3.0 | Scrolling song titles | long titles/artists scroll in the music card (option), media detection checks all Windows sessions (browser/YouTube), GitHub link next to the version |
| 1.2.1 | Smooth updates and English file names | opening a new version replaces the old running copy (fixes the missing what's-new window), version in the header, .bat files renamed to English |
| 1.2.0 | English language and quick exit | English/Portuguese interface (first-run choice + selector at the top and in System), Quit button with confirmation, documentation in English |
| 1.1.0 | modo claro e cards em teste | modo claro/escuro, categoria "Em teste" com o card Notificações, alinhamento do texto, preview com desmarcar e 4 cantos, orientação sem bagunça, pop-up de novidades, desinstalador |
| 1.0.10 | tempo da música preciso | contador de tempo sem pular nem repetir segundos |
| 1.0.9 | notificações pendentes | lista mostra o que está na central do Windows; filtro olha título e texto; nova tentativa após liberar permissão; status com fonte e motivo da falha |
| 1.0.8 | data sem cortes | tamanho da data calculado com o dia/mês mais largo; texto encolhe em vez de cortar |
| 1.0.7 | tempo da música estável | primeira correção do contador (substituída na 1.0.10) |
| 1.0.6 | notificações e visualizer | notificações sobre qualquer card, card Notificações, visualizador que acompanha o dispositivo de saída |
