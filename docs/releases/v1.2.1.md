# Rhino's Buddy Supervisor v1.2.1 — Smooth updates and English file names

Open-source (MIT) replacement for the Turing Smart Screen 3.5" software: put anything you want on the secondary screen
(hardware stats, clock, music, notifications, images) with a visual editor in your browser.

## What's new

- **Fix: the "what's new" window (and the language chooser) did not appear after updating.** If an older copy was still running
  (for example it had started with Windows), opening the new version only brought up the *old* window, so none of the new features showed.
  Now, when the program finds a copy of a **different version** already running, it asks that copy to quit, waits for it to close and starts the new one.
  If it is the same version, it just opens the existing window, as before.
- **The version is shown at the top of the page**, next to the program name (it is also in the **System** tab).
- **English file names:** `Uninstall Rhinos Buddy Supervisor.bat` (was `Desinstalar Rhinos Buddy Supervisor.bat`) and
  `Start Rhinos Buddy Supervisor.bat` (was `Iniciar Rhinos Buddy Supervisor.bat`). The uninstaller's prompts are now in English too (choices: 1/2/3 and Y/N).

## Good to know

- If you had a shortcut to the old `Iniciar ….bat`, it will stop working: point it to `Start Rhinos Buddy Supervisor.bat`.
- The first time you go from 1.2.0 (or older) to this version, the old copy cannot take part in the swap, so close it first (see below). From 1.2.1 on, opening a newer version replaces the running one automatically.

## How to update

1. In the folder of the old version, double-click the uninstaller — **`Uninstall Rhinos Buddy Supervisor.bat`** (in versions up to 1.2.0 it is named **`Desinstalar Rhinos Buddy Supervisor.bat`**) — and choose **1 (Update)**. Your data (layout, images and settings in `%APPDATA%\RhinosBuddySupervisor`) is kept. This also closes any copy still running.
2. Download `RhinosBuddySupervisor-v1.2.1-windows.zip` below, extract it anywhere and open `RhinosBuddySupervisor.exe`.

Without the uninstaller: close the program (Quit button, or end `RhinosBuddySupervisor.exe` in Task Manager), extract the zip over the old folder or into a new one and open the new executable; your data stays where it was.

## Requirements and notes

- Windows 10/11 and the Turing Smart Screen 3.5" (USB). CPU temperature needs LibreHardwareMonitor (guided install in `docs/GUIA_GIT_E_LICENCAS.md`, in Portuguese).
- The Notifications card is still in the **Testing** category: for it to read Windows, turn on *Settings → Privacy & security → Notifications → "Allow apps to access your notifications"*.
- The executable is not signed: Windows (SmartScreen) may show "unrecognized app". That is normal for new, independent programs.
- Features that depend on Windows (current track, notifications, audio capture, automatic start, the uninstaller, replacing a running copy) have not been run on a real PC; the automated tests cover their content and simulate the rest. If something behaves differently on yours, open an issue with the version and what happened.
